# Validação visual — Gerador de dados de teste

A rota `/settings` abriu corretamente no preview autenticado. A tela exibe o título Configurações, o cartão Dados de teste, o botão Gerar dados de teste e o aviso de que a ação não apaga nem substitui dados existentes.
